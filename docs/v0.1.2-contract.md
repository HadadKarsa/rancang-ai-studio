# v0.1.2 — contract (becik, 2026-11-22)

Locked shapes. Backend (forge) implements, UI (pixel) consumes. Do not change a
field name without telling the other side.

## 1. Auth — simple, first-party, cookie session

`AUTH_MODE=local` stays the default for the seeded owner. New: real accounts.

- `POST /api/v1/auth/register` `{email, password, name}` → `201 {user:{id,email,name}}`
  - password min 10 chars; email unique (409 `EMAIL_TAKEN`); sets the session cookie.
- `POST /api/v1/auth/login` `{email, password}` → `200 {user}`; wrong creds → `401 INVALID_CREDENTIALS`
  (same message for unknown email, no enumeration).
- `POST /api/v1/auth/logout` → `204`, clears cookie.
- `GET  /api/v1/auth/session` → `200 {user}` or `401`.
- Cookie: `rancang_session`, HttpOnly, SameSite=Lax, Path=/, 30 days, Secure when APP_URL is https.
  Value = the `sessions.session_token`. Row in `sessions` with `expires_at`.
- Password hashing: existing `src/lib/crypto/password.ts` (`hashPassword`/`verifyPassword`).
- `getSession()` in `src/lib/auth/session.ts` must read the cookie in cloud mode, fall back to
  the local user in local mode, and expire stale rows. `requireSession()` unchanged.
- Rate limit: `auth: { limit: 10, windowMs: 60_000 }` per IP on register+login.

## 2. Artifact library

Saved results, per user, independent of a project.

- `GET /api/v1/library?type=&q=&cursor=` → `{items:[{id,kind,title,projectId,projectName,documentId,documentType,createdAt,bytes}], nextCursor}`
  - `kind` = `document` | `export` | `wireframe`.
- `POST /api/v1/library` `{kind, title, projectId?, documentId?, payload}` → `201 {item}`
  - `payload` is stored as text: the markdown, the export bundle metadata, or the wireframe HTML.
- `DELETE /api/v1/library/:id` → `204`.
- Table `library_items`: `id, user_id, kind, title, project_id, document_id, payload, bytes, created_at`.
  New migration `migrations/002_library.sql`. Cascade on user delete.
- "Simpan ke library" is offered on the document page and on the write page completion state.

## 3. Wireframe HTML preview editor

- `GET /api/v1/projects/:id/wireframes` → `{screens:[{id,name,slug,htmlContent,viewport,orderIndex,isEntry}]}`
- `PATCH /api/v1/projects/:id/wireframes/:screenId` `{htmlContent}` → `200 {screen}`
  - max 512 KB, stored verbatim in `wireframe_screens.html_content`.
- Preview renders in a sandboxed `<iframe srcdoc>` (`sandbox="allow-scripts"`, no
  `allow-same-origin`), desktop/tablet/mobile widths from `viewport`.
- Editor: split pane, textarea left, live preview right, debounce 400 ms, "Simpan" + dirty state.

## 4. Rules

- Backend owns `src/lib/**` and `src/app/api/**`. UI owns `src/app/**` pages, `src/components/**`,
  `src/app/globals.css`. Nobody edits the other's files; ask instead.
- `tsc --noEmit` must pass before every commit. Commit small, Indonesian copy, no emoji.
- No full document batches for tests — use `?types=memory`.
